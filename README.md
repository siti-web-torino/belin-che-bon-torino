# Belin Che Bon — Torino

Sito statico in HTML, CSS e JavaScript con fotografie e illustrazioni locali. I font Bricolage Grotesque e DM Sans sono ospitati nel repository con le rispettive licenze OFL.

## Pubblicazione su Vercel

Repository: siti-web-torino/belin-che-bon-torino. Branch di produzione: main. Preset: Other. Directory radice del repository. Nessun comando di build, nessuna output directory personalizzata.

## Contenuti

I dati modificabili sono in SITE_DATA all’inizio di js/main.js. Dopo una modifica eseguire `node scripts/render.mjs` e salvare anche l’HTML aggiornato. Il sito non richiede una build durante il deploy.

Il menu include tre farinate illustrate, il listino completo e un configuratore. Le scelte del configuratore compongono un'anteprima. L'ordine si completa selezionando gli ingredienti su Glovo o Just Eat. Le indicazioni per allergeni e orari sono nelle sezioni «Senza glutine» e «Dove siamo».

Le direttive di indicizzazione si trovano in `index.html`, `robots.txt` e `vercel.json`.
